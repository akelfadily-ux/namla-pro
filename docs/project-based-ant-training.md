# Project-based ant training

`src/academy/trainingMissionFactory.ts` (project specs) + the existing
`MissionRunner` (Build Law §20). A multi-domain project (e.g. full-stack task
manager, REST API + database, secure-login design, data pipeline, agent workflow
with safety) requires several specialties and runs the full decentralized flow:

1. scouts investigate; 2. plans compete; 3. local quorum selects a plan;
4. ants volunteer; 5. temporary teams form; 6. builders produce artifacts;
7. reviewers inspect; 8. testers verify; 9. security ants review; 10. repair ants
fix failures; 11. evaluators score evidence; 12. skill passports update.

Reviews, verification runs, and repair rounds come from the real `MissionRunner`
report (a deterministic defect is injected and repaired). Teams come from the
existing `antTeams` system. No task is assigned; every ant wins work through the
voluntary market.
