# 26 · Assurance Profiles

A universal mandatory dual-subsystem design for every agent is **not** the V2 baseline.

## Profiles

| Profile | Requirement |
|---|---|
| `STANDARD` | one canonical implementation + normal independent verification |
| `HIGH` | independent semantic critic or materially different second method where it adds value |
| `CRITICAL` | genuine dual/N-version independent assurance; identical repetition does not qualify |

Baseline guidance:

| Stage | Profile |
|---|---|
| EER | HIGH |
| Plan | HIGH |
| Protocol | STANDARD |
| Pro | STANDARD |
| Colony A/B | CRITICAL by architecture |
| Son | HIGH |
| Leggo | STANDARD/HIGH |
| ProMax | CRITICAL |
| Namla Lab | STANDARD |

Independence must differ materially in algorithm, implementation, provider/model, evidence source, test-generation method, environment, or reasoning path.

AssuranceProfile controls required assurance, not authority.
